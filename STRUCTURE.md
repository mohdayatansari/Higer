# Repository Structure

Overview of all directories and documentation files in the **Higer** typeface repository.

---

## Directory Breakdown

| Path | Type | Description |
| :--- | :--- | :--- |
| **`Fonts/OpenType-PS/`** | Folder | Contains `Higer.otf` (PostScript/CFF outlines for print & design apps) |
| **`Fonts/OpenType-TT/`** | Folder | Contains `Higer.ttf` (TrueType outlines for desktop system & office use) |
| **`Fonts/Web-PS/`** | Folder | Contains `Higer.woff2` (Web-optimized font file for `@font-face`) |
| **`README.md`** | Document | Main project overview, specimen showcase, and quick navigation |
| **`INSTALL.md`** | Document | Desktop installation steps and CSS web embedding guide |
| **`FEATURES.md`** | Document | Complete glyph coverage, custom ligatures, and OpenType feature tables |
| **`ANATOMY.md`** | Document | Alpine design philosophy and vertical metrics |
| **`ROADMAP.md`** | Document | Release v1.0 overview and planned family expansion |
| **`STRUCTURE.md`** | Document | Directory overview (this file) |
| **`LICENSE.md`** | Document | Free personal & commercial usage terms and author attribution |
