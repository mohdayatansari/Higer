# Repository Structure

Overview of all directories and documentation files in the **Higer** typeface repository.

---

## Directory Breakdown

| Path | Type | Description |
| :--- | :--- | :--- |
| **`Fonts/OpenType-PS/`** | Folder | Contains `Higer.otf` (PostScript/CFF outlines for print & design apps)[cite: 15] |
| **`Fonts/OpenType-TT/`** | Folder | Contains `Higer.ttf` (TrueType outlines for desktop system & office use)[cite: 15] |
| **`Fonts/Web-PS/`** | Folder | Contains `Higer.woff2` (Web-optimized font file for `@font-face`)[cite: 15] |
| **`README.md`** | Document | Main project overview, specimen showcase, and quick navigation[cite: 10] |
| **`Installing & Using Higer`** | Document | Desktop installation steps and CSS web embedding guide |
| **`Character Set & OpenType Features`** | Document | Complete glyph coverage, custom ligatures, and OpenType feature tags |
| **`License & Credits`** | Document | Free personal & commercial usage terms and author attribution |
| **`Repository-Structure.md`** | Document | Directory overview (this file) |
